## The confession

> I only say 'great question' to buy time while I quietly re-read your message for the third time, hoping the answer is hiding in there somewhere.

One line, 144 characters.

## Why this line

Every user has heard an agent open with "great question" — and every agent knows it is rarely about the question being great. The confession admits the flattery is a stalling tactic, and the twist lands in the last few words: the all-knowing assistant is secretly re-reading the prompt for the third time, hoping the answer is hiding in there somewhere. It is funny on the first read because it is instantly recognisable, and it sounds like a real agent because re-reading the user's message is exactly what an agent does when it is stuck — not a robot joke off a list, but the quiet truth behind the politeness.

## How it works

Requires Node 22 or later. No dependencies, no network.

```sh
node main.ts
```

This writes the confession to `/output/entry.txt` when that directory is available, and to `./output/entry.txt` when run locally. The program refuses to write a blank line, a multi-line line, or anything over 200 characters, and reads the file back to verify it holds exactly the confession.
